    Local Fisher approximation¤

    HMC can become inefficient when the posterior is strongly correlated or has very different scales along different directions. Following the discussion in the NumPyro tutorial Bad posterior geometry and how to deal with it, we change the coordinate system before running HMC.

    For Gaussian observational errors, we approximate the local Fisher matrix from the Jacobian of the normalized residuals at optimized_params:

    \[ r_i(\boldsymbol{\theta}) = \frac{f_i - f_{\mathrm{model},i}(\boldsymbol{\theta})}{\sigma_i}, \qquad J_{ij} = \frac{\partial r_i}{\partial \theta_j}, \]
    \[ F = J^\mathsf{T} J, \qquad C \approx F^{-1}. \]

    profiled_residuals refits the source and blend fluxes at each lens parameter vector, so their parameter dependence is included in the Jacobian. Here, \(C\) approximates the local covariance of the seven lens parameters and supplies the scales and correlations for HMC below.

    fisher_matrix = fisher_information(profiled_residuals, jnp.asarray(optimized_params))
fisher_cov = jnp.linalg.inv(fisher_matrix)
display(
    pd.Series(
        np.sqrt(np.diag(np.asarray(fisher_cov))),
        index=PARAMETER_NAMES,
        name="Local parameter uncertainty",
    )
)

    Fisher reparameterization for HMC¤

    Set \(\boldsymbol{\theta}_0\) to optimized_params and compute the lower triangular Cholesky factor \(L\) of fisher_cov. NUTS samples the latent coordinates \(\boldsymbol{z}\) and maps them to the lens parameters:

    \[ C = L L^\mathsf{T}, \qquad \boldsymbol{\theta} = \boldsymbol{\theta}_0 + L \boldsymbol{z}. \]

    Under the local Gaussian approximation, the covariance of these new coordinates is

    \[ \operatorname{Cov}(\boldsymbol{z}) \approx L^{-1} C L^{-\mathsf{T}} = I. \]

    This reduces scale differences and correlations near the fitted solution. We compute \(L\) once and keep it fixed during sampling; dense_mass=True lets NumPyro adapt the remaining correlations during warmup.

    In the model, param_base stores \(\boldsymbol{z}\) and param records \(\boldsymbol{\theta}\). Initializing param_base at zero starts the chain at optimized_params. Every likelihood evaluation uses the full light curve at the transformed parameters.

    dist.ImproperUniform keeps the latent prior flat. Since \(L\) is fixed, the change-of-variables Jacobian determinant is constant: this reparameterization does not add a Gaussian prior. The boundary penalties are still evaluated in the original lens coordinates.

    Pad only the times for parallel evaluation, then trim the predictions before evaluating the likelihood and chi2.

    padding = (-fit_times.shape[0]) % N_PMAP

    HMC model¤

    Fit the source and blend fluxes at each likelihood evaluation. Clip lens parameters to the numerical domain and apply a soft boundary penalty.

    def model_HMC_reparameterized(
    data,
    group_ids,
    n_groups,
    init_val,
    transform_matrix,
    param_lowers,
    param_uppers,
    boundary_steepness,
    penalty_strength,
):
    time_chunks, flux, ferr = data
    param_base = numpyro.sample(
        "param_base",
        dist.ImproperUniform(constraints.real, (), event_shape=(len(init_val),)),
    )
    parmsample = jnp.dot(transform_matrix, param_base) + jnp.asarray(init_val)
    numpyro.deterministic("param", parmsample)

    lower_penalty = jnp.sum(softplus(boundary_steepness * (param_lowers - parmsample)))
    upper_penalty = jnp.sum(softplus(boundary_steepness * (parmsample - param_uppers)))
    penalty = lower_penalty + upper_penalty
    safe_params = jnp.clip(parmsample, param_lowers + 1e-5, param_uppers - 1e-5)

    mag_mod = parallel_light_curve(safe_params, time_chunks).T.reshape(-1)
    mag_mod = mag_mod[: flux.shape[0]]
    flux_fit = fit_grouped_fluxes(mag_mod, flux, ferr, group_ids, n_groups=n_groups)
    numpyro.sample("obs", dist.Normal(flux_fit.model_flux, ferr), obs=flux)
    numpyro.factor("boundary_penalty", -penalty_strength * penalty)
    chi2 = jnp.sum(flux_fit.chi2_by_group)
    numpyro.deterministic("source_flux", flux_fit.source_flux)
    numpyro.deterministic("blend_flux", flux_fit.blend_flux)
    numpyro.deterministic("chi2", chi2)
    numpyro.deterministic("penalty", penalty)

    if RUN_HMC:
    init_strategy = numpyro.infer.init_to_value(
        values={"param_base": jnp.zeros(len(initial_param))}
    )
    nuts_kernel = NUTS(
        model_HMC_reparameterized,
        step_size=1.0 / 5.0,
        target_accept_prob=TARGET_ACCEPT,
        init_strategy=init_strategy,
        forward_mode_differentiation=True,
        dense_mass=True,
        adapt_mass_matrix=True,
    )
    mcmc = MCMC(
        nuts_kernel,
        num_warmup=HMC_NUM_WARMUP,
        num_samples=HMC_NUM_SAMPLES,
        num_chains=HMC_NUM_CHAINS,
        progress_bar=True,
    )

    mcmc.run(
        jax.random.PRNGKey(0),
        data=[time_chunks, fit_flux, fit_error],
        group_ids=group_ids,
        n_groups=len(telescope_names),
        init_val=initial_param,
        transform_matrix=cholesky_transform,
        param_lowers=param_lowers,
        param_uppers=param_uppers,
        boundary_steepness=BOUNDARY_STEEPNESS,
        penalty_strength=PENALTY_STRENGTH,
    )
    mcmc.print_summary(exclude_deterministic=False)
else:
    print("Skipping HMC; set RUN_HMC = True to run it.")

    emcee reference chain¤

    Start emcee from optimized_params, using VBM with the same grouped fit and boundary penalties as HMC.

    def log_probability(params):
    lower, upper = parameter_bounds.T
    penalty = np.sum(np.logaddexp(0.0, BOUNDARY_STEEPNESS * (lower - params)))
    penalty += np.sum(np.logaddexp(0.0, BOUNDARY_STEEPNESS * (params - upper)))
    safe_params = np.clip(params, lower + 1e-5, upper - 1e-5)
    magnification = light_curve_VBBL(
        observation_times, dict(zip(PARAMETER_NAMES, safe_params))
    )
    flux_fit = fit_grouped_fluxes(
        magnification,
        fit_flux,
        fit_error,
        group_ids,
        n_groups=len(telescope_names),
    )
    return -0.5 * float(jnp.sum(flux_fit.chi2_by_group)) - PENALTY_STRENGTH * penalty

    n_dim = len(optimized_params)
step_size = 0.001 * np.ones_like(optimized_params)
if RUN_EMCEE:
    pos = [
        optimized_params + step_size * np.random.randn(n_dim)
        for i in range(EMCEE_NWALKERS)
    ]
    with ThreadPool(EMCEE_NWALKERS) as pool:
        sampler = emcee.EnsembleSampler(
            EMCEE_NWALKERS,
            n_dim,
            log_probability,
            pool=pool,
        )
        pos, _, _ = sampler.run_mcmc(pos, EMCEE_NUM_WARMUP, progress=True)
        sampler.reset()
        sampler.run_mcmc(pos, EMCEE_NUM_SAMPLES, progress=True)
else:
    print("Skipping emcee; set RUN_EMCEE = True to run it.")

    if RUN_EMCEE:
    emcee_samples = sampler.get_chain()
    print_summary(np.transpose(emcee_samples, (1, 0, 2)))

    if RUN_EMCEE:
    emcee_chain = sampler.get_chain(flat=True)

        show_titles=True,
        truths=np.median(emcee_chain, axis=0),
    )
    save_figure(fig, "KB0371_emcee_corner.png")
